One line of horror for make.fun's "One Line, One Chill" bounty: a hotel leaves a mint on the pillow every night, and on the last morning there are two mints — one for the narrator, and one for the guest who checked in under their name in 1987. The program validates the line (one sentence, 1–200 characters, a single line) and writes it to `entry.txt`.

## Run it

```sh
node main.ts
```
